### 🧠 Additional Edge Cases

- **Empty parameter value:** Key `foo`, value blank → URL shows `?foo=`. Delete it, URL cleans up.
- **Multiple params with same key:** add `key=a` then `key=b`. URL shows `?key=a&key=b`. httpbin’s `/get` args will show `key: ["a", "b"]`.
- **Body on GET request:** Enter body text, send GET to httpbin/get – body is **not sent** (the app ignores it). Request works fine.
- **Long URL:** Paste a long URL with many params – URL input displays it correctly; param editor syncs.
- **Concurrent tabs and collections:** Save a request from one tab, switch to another, load it – works independently.
- **Delete collection while expanded:** Collection disappears, no UI glitch.
